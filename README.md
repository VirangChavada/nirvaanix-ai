# AI Agent

Simple command-line AI agent backed by the OpenAI Responses API.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your API key:
   ```bash
   export OPENAI_API_KEY="your_key_here"
   ```

Optional:

```bash
export OPENAI_MODEL="gpt-4.1-mini"
```

## Run

```bash
python agent.py
```

Then chat in your terminal. Type `exit` to quit.
